# ระบบกิจกรรมพัฒนาผู้เรียน โรงเรียนวิทยาศาสตร์จุฬาภรณราชวิทยาลัย กาฬสินธุ์
Princess Chulabhorn Science High School Kalasin - Learner Development Activity System

## 🚀 วิธีเปิดใช้งานโปรเจกต์ (Getting Started)

1. ติดตั้ง dependencies:
```bash
npm install
```

2. รันระบบในโหมดพัฒนา (Development):
```bash
npm run dev
```

3. สร้างไฟล์สำหรับขึ้นเซิร์ฟเวอร์จริง (Production Build):
```bash
npm run build
```

## 🌟 ฟังก์ชันหลัก
- ระบบล็อกอินแบบ Unified Role Gateway (นักเรียน ครูที่ปรึกษา ผู้ดูแลระบบ)
- บันทึกและสะสมชั่วโมง 5 หมวดกิจกรรมตามเกณฑ์โรงเรียนวิทยาศาสตร์จุฬาภรณราชวิทยาลัย
- ระบบตรวจสอบและอนุมัติกิจกรรมแบบเรียลไทม์
- เชื่อมต่อ Google Sheets และ Google Apps Script
- พิมพ์เอกสารสรุปผลและรายงาน ปพ.5
